# Grayscale Digitizer

Превращает любое изображение в чёрно-белую матрицу оттенков (0-9).

## Возможности
- Загрузка любого фото (JPG, PNG, BMP, GIF, TIFF)
- Преобразование в оттенки серого
- Квантование на 10 уровней (можно менять 2-20)
- Отображение сетки с номерами оттенков в каждой ячейке
- Копирование матрицы в буфер
- Сохранение матрицы в TXT

## Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/ваш_логин/grayscale-digitizer.git
cd grayscale-digitizer

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите
python app.py
